# Pixel icons

The built-in pixel icons a project square can show (the icon dialog: 趣味、自然、生活、办公、开发、品牌、字母、其他).
A project stores one as `pixel:<id>` in `Project.Icon`, beside the Lucide names it already takes.

`pixel-icons.json` is generated by `tools/generate-pixel-icons.py`; do not edit it by hand. Format:

```json
{ "size": 24, "icons": [ { "id": "t-rex", "name": "t-rex", "source": "pixelarticons", "category": "fun", "bits": "<base64>" } ] }
```

`bits` is the 24 x 24 bitmap, 3 bytes per row, top row first, most significant bit = leftmost pixel. Every icon is
drawn on a 24 px grid in its source; the script rasterizes it into that grid (a pixel is set when its centre lies inside
a filled shape), so the app draws whole pixels and stays crisp at 24 px (one device-independent pixel per pixel) and
48 px (two). `PixelIcons` loads the file; `PixelIconView` draws an icon.

Left out: icons that are controls rather than pictures (arrows, alignment, check boxes, text formatting, media
controls...), the `-sharp` duplicates of pixelarticons, and the HackerNoon `solid` duplicates. HackerNoon ids carry an
`hn-` prefix.

To regenerate (from the unpacked npm packages):

```sh
python3 tools/generate-pixel-icons.py <pixelarticons>/svg <pixel-icon-library>/icons/SVG [contact-sheet.png]
```
